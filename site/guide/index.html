Install SARAS and connect your laptop, one step at a time.

This plain-language guide explains what to download, what happens during setup, how to connect your phone, and what to try if a step does not work. You do not need Python, VS Code, or coding experience.

Go to the Windows download →

Before you begin

  • A Windows 10 or Windows 11 computer for the SARAS Companion.
  • A phone with internet access for the SARAS mobile controller.
  • Keep the computer awake and connected to the internet while you control it from your phone.
  • PC control requires the Windows Companion to be installed and running. The phone website by itself cannot control a computer.

What SARAS installs

The Windows download installs the Companion on your PC. On your phone, open saras.farhanbalouch.com and optionally add the website to your home screen. The phone version is a web app; this setup does not install an Android APK or iPhone App Store app.

PART 1 · YOUR WINDOWS COMPUTER

Download and install the Windows Companion

  1. Open the download page. On your Windows computer, visit SARAS Download and select the current Windows setup file.
  2. Wait for the download to finish. Open your browser’s Downloads list, or open the Downloads folder in File Explorer. The file name includes “Windows-x64-Setup.exe”.
  3. Start setup. Double-click the setup file and follow the on-screen steps. Keep the default install location unless you have a reason to change it.
  4. Understand the Windows warning. The current preview is not code-signed. Windows may show a SmartScreen or “Unknown publisher” warning. This warning cannot be truthfully removed without a trusted code-signing certificate and reputation. Only continue if you intentionally downloaded the file from this official SARAS site and the release details match. Never turn off Defender or your antivirus.
  5. Open SARAS Companion. After installation, open SARAS Companion from the Windows Start menu. The companion is the laptop application. It should stay running while your phone is connected.

If setup says SARAS is already running, close any open SARAS Companion windows and its notification-area (system tray) icon, then run setup again. Save any work first.

PART 2 · YOUR PHONE

Open SARAS on your phone

  1. On your phone, open saras.farhanbalouch.com in Safari or Chrome.
  2. Sign in using the account option shown on the page. Complete your display name/profile if SARAS asks.
  3. To make SARAS easy to reopen, use your browser’s Add to Home Screen or Install app option. This adds a shortcut to the phone; it does not install a separate APK.
  4. Open Devices or Add laptop in SARAS. Leave this page open while pairing.
PART 3 · CONNECT THE TWO

Pair your phone with your laptop

Keep both screens in front of you. Pairing uses a short-lived code and asks you to approve the request on the laptop.

  1. In SARAS Companion on Windows, choose Show QR / generate new code. If asked, confirm that this is your laptop.
  2. On your phone, tap Add laptop and choose the scanner. Allow camera access when your browser asks.
  3. Point the phone at the QR code on the computer. Keep the full code inside the scan box and hold still for a moment.
  4. If scanning does not detect it, use the manual code. In the companion, generate a fresh code. Type the digits into the phone’s Add laptop screen before the countdown expires. The phone’s ordinary camera may open a link; that is okay, but use SARAS’s manual code option if its scanner does not continue.
  5. Compare the pairing request on both screens. Approve it on the laptop only if you recognize the account and are pairing your own device.
  6. Choose the permissions you want this phone to have, then finish the connection. You can disconnect or revoke a paired device from account/device settings.

Pairing code expired?

Nothing is broken. Codes expire for safety. In SARAS Companion generate a new code, then start pairing again on your phone with that new code. Do not reuse an old screenshot or share a pairing code with anyone.

PART 4 · FIRST USE

Check that your laptop is connected

  1. In the mobile controller, open My Devices and select your laptop.
  2. Check that its status is online. If it says offline, make sure the companion is open and both devices have internet access.
  3. Start with a simple, safe action, such as opening Calculator. Confirm that the result appears on the laptop.
  4. For chat or AI-generated answers, you may need to add your own AI provider key in the companion settings. Do not paste private keys into a public chat or share them with another person. Some basic supported PC actions can work without an AI provider, while AI conversations may show a provider-configuration message.

The computer must remain powered on, awake, online, and running SARAS Companion for remote actions to work. A phone cannot control the PC while the companion is closed or disconnected.

Quick fixes for common problems

“SARAS is already running” during installation

Close the companion window and its small tray icon, then start setup again. If it still appears, restart Windows and try once more before opening SARAS.

The QR scanner opens but does not recognize the code

Check camera permission for the browser, brighten the laptop screen, fit all four QR corners inside the scan frame, and hold steady. If it still does not detect, generate a new code and enter its digits manually. Manual pairing is an intended fallback.

The laptop appears offline

Open SARAS Companion on Windows and check that the laptop has internet. Refresh the mobile device list. Do not pair again unless the device was removed or revoked.

A command says no AI provider is configured

The companion can receive supported direct PC actions while AI chat needs a configured provider. Add your own provider in the companion settings if you want AI-generated replies. This message does not mean the pairing failed.

I am asked to sign in again

Use the same sign-in method and account that owns the laptop. Browser privacy settings, private browsing, cleared site data, or an expired session can remove the saved sign-in. Do not save an account password in a shared or public device.

I want to disconnect my phone

Use the SARAS device or security settings to remove/revoke the phone. You can also stop the companion on Windows. A removed device should be paired and approved again before it can reconnect.

Still stuck? Visit the SARAS help and FAQ page or contact SARAS. Do not send passwords, API keys or active pairing codes.

Version, safety and updates

Check the download page for the current version, file details, and the latest release notes. This preview is unsigned, so Windows may show a publisher warning. A website description or search listing cannot certify a downloaded program. Keep Microsoft Defender and other security tools enabled, and only download from the official SARAS download domain.

SARAS is under active development. Available commands, voices, AI providers and mobile features depend on the current release, Windows permissions, selected models and your configuration. Read the security information and privacy notice before using sensitive controls.
