Privacy notice

How the SARAS Next private pilot handles microphone input, activated cloud transcription, chat data and laptop permissions.

Pilot notice · Updated 19 October 2026. This describes the current pilot, not a promise about a future public service.

This information website

This website does not ask for passwords, payment details, microphone access or an email address. It has no advertising or analytics scripts added by SARAS. Hosting infrastructure can process standard request information such as IP address and browser details under its own terms.

Microphone and speech

The Windows companion processes background wake-word audio locally. When optional enhanced recognition is enabled, an activated request may be sent through the configured SARAS server to Groq for transcription. AI and speech providers apply their own data policies. Do not dictate confidential information unless your chosen service is appropriate for it.

Chats, configuration and PC actions

The application stores chat and configuration data in its configured local or server storage. Shared files and approved tool requests are processed to carry out the requested action. Pairing and credentials should remain private. This website does not receive your laptop files.

Cloud providers and voices

Depending on configuration, requests can use Groq, Gemini or OpenRouter. Laptop-generated speech is relayed to the paired app when voice access is enabled. Voice licenses and processing capabilities vary by model.

Your controls

You can pause the microphone, hide the desktop character, disable PC access, stop an action and change permissions. Contact the operator of your configured server about data stored there. Public service retention schedules and user account deletion procedures must be finalized before public registration opens.

Questions

Find the founder’s official website through our contact page. Do not send passwords, API keys or pairing tokens in support messages.
