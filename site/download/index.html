About the Windows publisher message

This preview is not code-signed, so Windows may show an “Unknown publisher” prompt. That prompt means Windows cannot verify a signing identity for this file; it is not a Microsoft safety approval. Keep Microsoft Defender enabled. Separate clean-computer and independent security reviews are still pending. If you prefer a signed, fully reviewed release, wait before installing.

A clear first setup

What happens after you download?

Downloading the Windows companion is the first step. Phone control is optional and uses the separate online SARAS mobile website.

01 · REQUIREMENTS

Check your Windows PC

Use a Windows 10 or Windows 11 computer with a 64-bit processor and enough free storage for the setup file and installed application. Keep your Windows security software enabled.

02 · INSTALL

Run the setup file

Download the Setup EXE, open it from your browser’s Downloads list, and follow the installer. SARAS includes its app runtime; you do not need to install Python, VS Code or a programming environment.

03 · CONFIGURE

Choose your own settings

Open SARAS Companion and choose the permissions, microphone and speaker settings you want. AI conversation needs your own supported provider key; it is not embedded in the installer.

04 · OPTIONAL PHONE CONTROL

Connect your mobile

On your phone, open SARAS mobile, sign in, scan the laptop QR code or enter a temporary code, then approve the matching request on the laptop.

Version numbers, simply explained

Why is dev.8 newer than dev.10?

The current public installer is SARAS Next 2.0.0-dev.8, published 29 October 2026. It belongs to the newer 2.0.0 development line.

0.2.0-dev.10 was published earlier, on 21 October 2026. Its “dev.10” counter is higher, but it is part of the older 0.2.0 line. Version counters only compare builds inside the same line; the full version and release date show the order.

0.2.0-dev.9 appears in older pilot notes, but it is not a published GitHub installer release. 2.0.0-dev.7 was a draft without a setup EXE. Only download versions that have a verified installer listed.

Download questions

Before you install SARAS

Do I need to install Python or VS Code?

No. The Windows Setup EXE includes its required application runtime. You can install SARAS without a separate Python, VS Code or coding setup.

Will the installer make my phone control the PC automatically?

No. Install and open the Windows Companion first. Phone control is optional: sign in to the separate SARAS mobile website, pair by QR or a short-lived code, and approve the connection on the laptop.

Why might Windows show “Unknown publisher”?

This preview is not code-signed. Windows may therefore show a publisher prompt. Keep Defender enabled and install only if you are comfortable using an unsigned preview; a signed public release is not available yet.

Is every AI feature ready without an API key?

No. Basic companion and configured Windows controls are separate from AI-provider features. AI conversation requires you to add your own supported provider key in SARAS settings. The installer contains no private provider key.
