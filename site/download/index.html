Before you begin

  • Windows 10 or 11, 64-bit.
  • A microphone and speakers for voice interaction.
  • Internet for cloud AI, mobile connection and research.
  • Available storage for the application and selected voice models.
  • Use your own device and save open work before testing PC actions.

What you will download

A Windows companion package, not a development project. It contains the app runtime and the models specified in that release. Each user needs their own configuration and pairing; the founder’s credentials are never part of a download.

Setup in three steps

  1. Extract or install the verified package.
  2. Open SARAS and choose microphone, speaker and permissions.
  3. Connect to the supported server, pair the companion, and test a simple task.

Release status

This is an unsigned development pilot. Public account registration, a signed installer, a public update channel and final distribution review are still pending.
