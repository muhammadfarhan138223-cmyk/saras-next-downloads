SARAS COMPANION HELP

SARAS Windows Companion: every button and setup step explained

Updated 11 November 2026. This guide describes the new separate-page Companion interface in the dev.11 release. Earlier versions can have older labels and the confusing hidden AI fields. Use the current Windows download page to check your installed version.

Start in five steps

  1. Install SARAS and open its version-labeled Desktop or Start menu shortcut.
  2. Open Devices. Create a QR/code, sign in on your phone at SARAS Mobile, and approve matching codes on both sides.
  3. Open Security and allow only the Windows controls you want.
  4. Open Settings → AI connection on this laptop. Choose provider, paste key, load/select a model, save and test.
  5. Start account connection. On mobile, open My Devices → Control laptop. Keep the laptop awake and online.

Where do I enter my SARAS AI API key?

In the Windows Companion, open Settings → AI connection on this laptop. Select the matching provider, paste its key, click Load available models, choose a model and Save & activate AI. Then Test selected AI. Keys are stored encrypted on your Windows account and are not entered into the public download website. The paired phone uses your laptop’s configured AI connection.

Use one Gemini key for chat and voice

Save a Gemini key and chat model in Settings → AI connection. The Gemini voice panel reuses the same encrypted key, even if you later activate another saved chat provider. Sync speech models and voices, select them separately, allow speech text sharing and Save voice choice. Generate a voice test and press Play; use your own-language sample to assess pronunciation. Your paired phone can use that configured voice through the laptop while mobile voice permission is enabled. Existing Windows voices remain available when Gemini voice is disabled.

Chat and speech use different model capabilities. Listing a model does not guarantee quota or successful generation. No real Gemini key was included or used for release tests; account-specific access, latency and pronunciation must be tested by you. Gemini does not provide exact lip timing in this integration. The current Google speech-generation documentation describes model and language support; Urdu and Saraiki quality is not guaranteed here.

What is the App password field for?

The App password belongs to the older local/private controller mode and stays under Advanced. It is not Google’s password or the mobile SARAS app PIN. Normal online account pairing does not require it. Do not reset it just to configure AI. Resetting it can sign out affected local sessions.

What do the sidebar pages do?

Home gives a connection overview. Devices handles pairing and connection. Security handles local permissions. Activity shows status, approvals and logs. Settings contains AI, shared folder, startup and updates. The selected page is highlighted; loading, success and error messages are shown beside the relevant action.

Understand the status before trying again

  • Paired, offline: account ownership is saved, but the Companion bridge is not online. Start account connection and inspect Activity. Do not repeatedly create new pairings.
  • Online, access disabled: the laptop is reachable but PC actions are not authorized/enabled.
  • Loading: wait for a final status; a request being received does not prove completion.
  • Stop current PC access: use STOP PC access before switching connections, changing shared folders or applying an update.
  • Model 404: check provider and current model ID with Load available models; test that provider. Quota, billing and provider outages are separate errors.
  • Wrong or expired QR/code: generate a fresh code and approve the matching request. Do not reuse old codes.
  • PIN on every internal page: refresh/apply the current PWA update. Internal Control laptop/My Devices navigation should retain unlock; leaving the app locks it.
  • Missing shortcut: use the latest installer’s Desktop shortcut option. New shortcuts include the full development version. Closing the app is not a reason to reinstall every time.

Which features need internet or an AI key?

The online phone controller needs internet on both devices and a running Companion. Manual supported Windows actions do not require an AI key. General AI chat and ambiguous natural-language planning require a valid provider/model/quota. Installed Windows voices and bundled local recognition can work locally; browser recognition, web research, weather and provider services can require internet. An installed PWA opening offline does not mean it can remotely control an offline PC.

Permissions and privacy

Share only your chosen folder and approve sensitive actions. Do not share API keys, app passwords or pairing codes with others. Disconnect, Block and Remove in the mobile dashboard revoke device access; removing a list entry does not uninstall the Windows app. The current installer is unsigned and Windows may show a publisher warning. A guide or matching checksum is not a Microsoft safety certification.
