Files, folders & workspace search

Keep routine file work in a shared workspace. Learn how SARAS Next files, folders & workspace search works, how to set it up and what to expect.

FEATURE GUIDE

Keep routine file work in a shared workspace.

Supported tools create, read, rename, move, search and remove files or folders within the configured shared workspace. This keeps file access tied to the location you deliberately selected.

Try this

Find a named document in your shared folder, or create a new notes folder.

Get it ready

Select a shared folder and grant file-tool permission. Review the exact requested change.

What to expect

Files outside the shared scope are not automatically accessible. Renaming or removing files can affect other apps; keep backups and verify the result.
