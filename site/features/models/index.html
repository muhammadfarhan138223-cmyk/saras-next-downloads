FEATURE GUIDE

Use configured providers for different kinds of work.

The code supports provider routing with Groq, Gemini and OpenRouter configurations. Task processing depends on available providers, models and valid credentials.

Try this

Ask a normal question, request a structured explanation, or use a supported PC workflow.

Get it ready

Set valid provider credentials in your own configuration. The downloadable app must not contain the founder’s keys.

What to expect

Provider quotas, model changes and service availability apply. Routing does not guarantee every request will succeed or be instantaneous.
