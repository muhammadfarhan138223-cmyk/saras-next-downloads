Open & close supported applications

Move between tasks with fewer clicks. Learn how SARAS Next open & close supported applications works, how to set it up and what to expect.

FEATURE GUIDE

Move between tasks with fewer clicks.

The companion routes supported app requests through its app catalogue and window actions. You can request an app launch or closure and check the execution result in the app.

Try this

Ask to open Calculator or a configured editor, then review the result.

Get it ready

Grant app-control access and make sure the requested program is installed and supported.

What to expect

App names, multiple windows, unsaved work and Windows privilege levels can affect closure. A process accepting a request does not always mean the window has closed.
