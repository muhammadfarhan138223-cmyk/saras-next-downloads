SARAS NEXT / FAQ

Let’s clear a few things up.

Answers about Windows setup, wake words, internet access, mobile control, voice models and privacy.

Does SARAS run on my phone?+

The web app can be opened on a phone. PC actions and laptop-generated voices require a paired Windows companion that remains powered on and connected.

Is the microphone always recording to the cloud?+

Background wake-word processing runs locally. If enhanced recognition is enabled, an activated request can be sent through the SARAS server to Groq. Background wake audio is not uploaded by that feature.

Is every language supported equally?+

No. Recognition and pronunciation depend on the selected language, microphone and installed voice model. Aegis Urdu currently has verified model-derived speech timings. Other models can speak without that timing support.

Can it control absolutely anything?+

No. Supported tools and configured permissions define what it can do. Windows may require administrator approval for some actions. Turning Wi-Fi off can disconnect remote control.

Can I stop it speaking?+

Use the stop control or click the speaking desktop character. Voice interruption is also available; its reliability depends on the microphone and speaker echo.

Is SARAS free and ready for public resale?+

Pricing has not been announced. This is a private pilot, and some voice models have personal-use restrictions. The current bundle is not commercially cleared.

What does lip sync mean here?+

The desktop uses a two-dimensional character rig with mouth poses driven by speech timing where the selected voice supports it. It is not a fully rigged 3D animal or a guarantee of film-quality animation.

How are updates delivered?+

This pilot uses versioned releases. A signed, public automatic update service is not yet available. Always check the release source before installing an update.
