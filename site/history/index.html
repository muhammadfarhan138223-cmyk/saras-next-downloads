SARAS NEXT / RELEASE HISTORY

Every public generation has a story.

SARAS has changed through real development iterations. This page records the public Windows generations we can verify, what improved in each, and the limitations to know before installing an older build.

Download the current generation →

Which version is current?

SARAS Next 2.0.0-dev.8 is the newest published Windows installer listed here (29 October 2026). The earlier 0.2.0-dev.10 has a higher “dev” number but an older product version and earlier release date. Version numbering changed between those development lines; the date and full version identify which is newer.

How SARAS evolved

The project began as a Windows-first companion and local controller: the computer did the work locally, while phone access depended on private network setup. This was useful during development but harder for a new user to configure. The newer V2 generation was built around a separate online mobile controller, account-based device pairing, and laptop-side approval. The Windows app still performs Windows actions on the user's own computer.

These are development releases, not a claim that every feature is finished. Only installer files that exist in the official release archive are listed below.

Current generation · SARAS Next 2.0.0-dev.8

Published 29 October 2026 · Windows x64 · Setup EXE · 284,038,122 bytes.

  • What improved: the phone controller is hosted separately at saras.farhanbalouch.com; pairing uses an account, a temporary code or QR flow, and approval on the laptop. The installer includes its Python runtime and offline speech recognition, so users do not need to install Python or VS Code separately.
  • What to expect: configure your own AI provider key if you want AI-generated conversation. The PC must stay awake, online, and running the Companion for phone control.
  • Known limits: this is an unsigned preview, so Windows can show “Unknown publisher.” Separate clean-computer and independent security reviews have not been completed. The release notes say physical-device review is pending.
  • Integrity: compare the downloaded installer’s SHA-256 with 8cfe79a123d54bc116c78195771db298d504180f17d10b5a4ebb59a02273b5f9. A matching hash confirms file integrity against the published value; it does not prove publisher identity or certify the software.

Legacy generation · SARAS 0.2.0-dev.10

Published 21 October 2026 · Windows x64 · Legacy unsigned setup · 283,854,445 bytes.

  • What it introduced: a self-contained Windows package with Python, desktop characters, offline speech recognition, Windows speech, and user-supplied AI provider configuration.
  • What it did well: it was designed to run many everyday actions on the laptop and did not require separate Python or coding-tool installation.
  • Why it was replaced: its release notes say phone access needed private Tailscale on both devices or a user-configured HTTPS server. It did not have the current account-based public pairing flow, so setup was more technical.
  • Who should use it: only someone who specifically wants to inspect or test that older architecture. It is not recommended for a new installation and is not the current cloud-pairing app. Do not install it over a newer build unless you have backed up your data and intend to test a legacy version.
  • Integrity: the GitHub release lists SHA-256 1f3f856f09afd49a8c813e2a7b572478bf4cdcf85b948c7e47ef9e7cd7347985. This checksum is not a publisher signature.

Why are earlier development numbers missing?

Labels such as dev.1, dev.2 or dev.7 can refer to internal builds, drafts, or incomplete transfer files; a label alone does not make a safe public installer. When this archive was checked, the official GitHub release list contained a complete public installer for 2.0.0-dev.8 and an earlier 0.2.0-dev.10 installer. The 2.0.0-dev.7 entry was a draft without a setup EXE, so it is not listed as a download. Earlier private test builds are not linked because their release files, integrity details, and suitability for public use have not been verified.

When a later release replaces the current one, this page should keep the former release marked as legacy and add a download only after its official file, release notes, version, and checksum are confirmed.

Stay safe when downloading

Download SARAS only from this official site or its linked official GitHub release. Keep Microsoft Defender enabled. Unsigned preview downloads may trigger a Windows publisher warning. Do not run a file if its version or checksum does not match the release information.

For a simple first-time setup, follow the SARAS download and installation guide. For the currently recommended installer, visit the download page.
