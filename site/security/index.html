SARAS NEXT / SECURITY

Security and responsible use

Learn how SARAS Next pairing, action permissions, emergency stop and microphone controls work.

Pair the right device

Use the pairing code only with your own companion. Keep your app password and any automation bypass token private. Do not paste credentials into a support screenshot.

Choose permissions deliberately

Share only folders the assistant needs. Mouse and keyboard input can change or submit data. Shutdown and radio controls can interrupt your work or disconnect the laptop.

Keep a way to stop

The app has access and emergency-stop controls. The desktop character can stop speech. Voice interruption depends on input quality, so keep the visible control available.

Check the release source

The current pilot is unsigned. Public signing and update verification are release requirements. Do not install files claiming to be SARAS from an unknown sender.

Report a problem

Include the release version, Windows version, action requested and the non-sensitive error text. Use the founder link on the contact page to find an available contact method.
